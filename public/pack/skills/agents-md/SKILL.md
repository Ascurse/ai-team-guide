# AGENTS.md: только то, без чего агент ошибётся

Агент сам читает дерево файлов, package.json и README. AGENTS.md нужен для того, чего из репо не вывести. Всё упомянутое в нём агент выполняет как приказ, поэтому лишняя строка — это лишнее поведение.

## Форма файла

Не больше ~40 строк. Только эти секции, пустые — не писать:

```markdown
# AGENTS.md

## Команды
<!-- только нестандартное или с предусловием -->
- e2e: сначала `docker compose up db`, потом `pnpm test:e2e`
- пакетный менеджер: pnpm (не npm/yarn)

## Нельзя
<!-- только то, что в этом репо приводит к реальному ущербу -->
- `pnpm db:migrate` = `prisma migrate deploy`: только против локальной БД

## Подвохи
<!-- неочевидные связи и ловушки этого репо -->
- `legacy/` (jQuery) живой: импортируется из `app/admin`

## Проверка перед «готово»
- `pnpm typecheck && pnpm lint && pnpm test`
```

## Фильтр строки

Каждая строка проходит тест: **«Без неё агент в этом репо ошибётся? Да/нет»**. Нет — строки нет.

Не проходят: структура папок, стек, общие практики (маленькие коммиты, тесты на новое поведение, не коммитить секреты), стандартные команды, которые видны в `scripts`.

Источник строки — только то, что ты видел в этом репо (файлы, конфиги, README, CI). Общее знание о библиотеке или фреймворке («у pytest-django бывает так») — это вопрос владельцу, а не строка файла.

## «Подробно»

Если просят подробно — подробность означает больше подвохов и предусловий именно этого репо. Чего не видно из файлов — список вопросов владельцу в ответе, а не правила в файле.

## CLAUDE.md рядом

Если в репо есть CLAUDE.md — его содержимое одна строка `@AGENTS.md`. Иначе Claude Code AGENTS.md не читает.

## Ответ пользователю

1. Файл.
2. Вопросы владельцу (чего не видно из репо), не больше 5.
