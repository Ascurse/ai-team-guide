# pack — композер инструкции для `/compact`

Собирает готовую строку `/compact <инструкции>` из двух ортогональных осей:
**size** (насколько сжать) × **mode** (что считать важным).

## ВАЖНО: это композер, не замена компакции

Скилл **не запускает** компакцию — компакция это операция харнесса, а скилл исполняется как
обычный ход и не может вызвать слэш-команду. Задача скилла — выдать готовую строку, которую
пользователь **сам вставляет** в настоящий `/compact`. Не притворяйся, что сжал контекст.

## Шаги

1. Задай два вопроса одним шагом — в Claude Code одним вызовом **AskUserQuestion**; без него (например, Codex) — одним текстовым сообщением с пронумерованными вариантами:
   - header `Size`, вопрос «Насколько сжать?» — опции: **Light**, **Medium (Recommended)**, **Aggressive**
   - header `Mode`, вопрос «Что считать важным?» — опции: **Continuity**, **Decision-pass**, **Debugging**, **Review-handoff**
2. Собери **одну** строку `/compact`, слив фрагмент mode (что оставить/выкинуть) + фрагмент size
   (степень сжатия) в связное предложение. Бери фрагменты из таблиц ниже — не выдумывай новые режимы.
3. Выведи **только** финальную строку в code-блоке (чтобы копировалась в один клик) плюс одну строку
   пояснения, что выбрано. Ничего больше не делай — не редактируй файлы, не зови другие инструменты.
4. Если сработало правило «лучше /clear» (см. ниже) — добавь короткий нудж отдельной строкой.

## Перед компакцией: контракт выносится в файл

Сводка компакции факты почти не переносит, и переносит их по принципу «всё или ничего»: 106 из 108
сводок несли 0 из 10 контрольных фактов, ни одна не несла строгое подмножество. Рассчитывать, что
модель «сама учтёт», тоже нельзя: добровольное обращение агента к памяти — 0 вызовов за 114 ходов
при доступном, задокументированном и засеянном хранилище. Доставка работает только со стороны
харнеса — то есть из файла, который перечитывается после компакции.
(Q8/Q9, `~/Documents/AI_workflow_research/frontend_ai_skills/synthesis/claims.md:465-466`.)

Поэтому, если в сессии есть незакрытые обязательства, перед выдачей строки выпиши их файлом в
scratchpad и добавь путь в саму инструкцию `/compact` («перечитай <путь> перед продолжением»).
Долговечная единица — **исполняемый контракт**, а не восстановленные данные: незакрытые обязательства,
маршрут, путь вывода, формат, граница допустимого. Арм, восстановивший все 256 отображений кодбука
после семи компакций, маршрут и правила сериализации не восстановил (Q15, `claims.md:472`).

## Size-фрагменты (степень сжатия)

- **Light** — «сохрани максимум деталей: все решения, правки файлов, открытые треды и текущее
  состояние; сожми только вывод инструментов и объяснения»
- **Medium** — «выкинь вывод команд, промежуточные размышления и то, что не подтвердилось»
- **Aggressive** — «сожми сильно: по одной строке на пункт, всё закрытое и весь процесс выкинь»

## Mode-фрагменты (что считать важным)

- **Continuity** — «оставь текущую задачу, какие файлы уже тронуты и зачем, что работает, что
  сломано, следующий шаг»
- **Decision-pass** — «оставь только точный вопрос на решение, скорректированные findings,
  референс-файлы и standing-констрейнты; выкинь всю историю реализации и exploration»
- **Debugging** — «оставь симптом, воспроизведение, что уже проверено и отвергнуто, текущую
  гипотезу; из логов только релевантные строки»
- **Review-handoff** — «оставь что было сделано, какие файлы изменены и почему, какие тесты
  гоняли и результат; процесс реализации выкинь»

## Правило сборки

Итог = `/compact ` + mode-фрагмент + `; ` + size-фрагмент, слитые так, чтобы не дублировать
«оставь/выкинь». Порядок: сначала ЧТО оставить (mode), потом НАСКОЛЬКО жать (size).

Пример (Continuity + Aggressive):
```
/compact оставь текущую задачу, тронутые файлы, что сломано и следующий шаг; сожми сильно — по одной строке на пункт, всё закрытое и процесс выкинь
```

## Нудж «лучше /clear»

Компакция жжёт токены на суммаризацию. Если из ответов видно, что пользователь уходит на
**новую несвязанную задачу** (mode звучит как «начать с чистого листа», а не продолжить), добавь:
«Если задача новая и несвязанная — дешевле `/clear` (в Codex — `/new`), компакт зря жжёт токены на суммаризацию».

## Связка с cost-discipline

Из глобальных правил (`~/.claude/CLAUDE.md` / `~/.codex/AGENTS.md`): за ~150K контекста — `/compact` (продолжаем) или `/clear` (новая задача; в Codex — `/new`).
Decision-pass — это подготовка узкого контекста под разбор на старшей модели (Fable/Opus в Claude Code, старшая gpt-6.x в Codex; см. память
`opus-escalation-flow`): после вставки строки пользователь переключает модель вручную.
