# Как работать с AI: ChatGPT, Codex, Claude и Claude Code

Практический гайд на русском: как ставить задачу, управлять контекстом, проверять результат и выбирать модель. Главный экран показывает 3D-стопку контекста, в тексте есть интерактивные симуляторы.

Сайт: https://ascurse.github.io/ai-team-guide/

Файл для чтения без сети лежит в [релизах](https://github.com/Ascurse/ai-team-guide/releases/latest).

## Разработка

```bash
yarn install
yarn dev
```

- `yarn test` проверяет учебную модель сессии.
- `yarn build` собирает сайт в `dist/`.
- `yarn offline` после сборки делает два HTML в `dist-offline/`: `ai-team-guide.html` и `ai-team-guide.en.html`.
- `yarn check:en` после `yarn build && yarn offline` ищет на английских страницах кириллицу и сверяет с русскими число виджетов и автоссылок. В CI не входит.

Текст лежит в `src/content/guide.md`, модель сессии в `src/lib/sim.js`. Файл копируется без изменений из заметок автора, поэтому `[[ссылки]]` в нём снимаются при сборке.

## Английская версия

Страницы лежат под `/ai-team-guide/en/` с теми же адресами, шаблон один на оба языка: `src/layouts/GuidePage.astro`.

- Текст гайда: `src/content/guide.en.md`. Перевод ведётся вручную: когда меняется `guide.md`, тот же кусок надо поправить и здесь.
- В файле должны быть те же семь заголовков `#` и якоря виджетов из таблицы в `src/lib/guide-paths.js`.
- Ссылка на раздел пишется в прямых кавычках: `"Name"`. Знак препинания ставится за кавычками, иначе ссылка не появится.
- Данные виджетов: `src/data/en/*.js`, переводятся на месте. Менять можно только тексты: id, URL и порядок сверяет `test/i18n.test.mjs`.
- Строки интерфейса: таблица `T` в каждом компоненте и `src/scripts/strings.js` для клиентских скриптов.
- Архив скиллов остаётся частично на русском.

Сайт выкатывается на GitHub Pages при пуше в `main`. Релиз с офлайн-файлом создаётся тегом `v*`.
